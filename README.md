# Student Record Management

A simple Python project to manage student records.

## Features

- Add student
- View all students
- Search student by roll number
- Delete student
- Exit the program

## Concepts Used

- Python
- Variables
- Lists and Dictionaries
- Functions
- If-Else Statements
- Loops
- User Input
